# Bash Scripting Practice

A simple collection of Bash scripts I wrote while learning Linux administration and automation. 

## What's in this repo?
- `file_checker.sh`: Checks if a specific file exists.
- `ram_checker.sh`: Shows current RAM usage.
- `port_scanner.sh`: A basic script to check open ports.
- `service_manager.sh`: Starts, stops, or checks basic Linux services.
- `server_updater.sh`: Runs basic `apt update` and `upgrade` commands.
- `dc_checker.sh`: A quick check for Docker Compose containers.

## Why I made this?
To practice core Bash concepts like:
- Variables
- If/Else conditions
- Basic loops
